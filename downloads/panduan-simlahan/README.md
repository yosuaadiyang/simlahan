# Unduhan panduan HTML SimLahan

- [Unduh panduan untuk dibaca offline](panduan-offline.zip?raw=1): ekstrak ZIP dan buka `panduan.html` dengan peramban. Seluruh gambar ada dalam satu HTML.
- [Unduh paket website dan embed](panduan-web.zip?raw=1): ekstrak ZIP, upload seluruh folder `panduan-simlahan` ke hosting, lalu tempel kode iframe.
- [Kode iframe](kode-embed.html): sesuaikan `src` dengan alamat hasil upload.

Kedua versi memuat 777 langkah, 41 layar pendamping, seluruh bab dan lampiran. Gambar memakai data fiktif. Pencarian, daftar isi dan pembesar gambar tersedia. Versi web telah diuji di dalam iframe pada desktop dan ponsel, termasuk pemuatan 818 gambar sebelum cetak.

`SHA256SUMS.txt` mencatat checksum paket. Paket offline berisi HTML mandiri berukuran sekitar 76 MiB setelah diekstrak. Versi web memakai gambar terpisah yang dimuat saat dibutuhkan.
