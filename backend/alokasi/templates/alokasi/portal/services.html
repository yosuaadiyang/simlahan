Permohonan alokasi tanah

Permohonan pengalokasian tanah untuk kegiatan usaha atau pembangunan. Tersedia tiga jenis:

    {% for value, label in allocation_types %}
  • {{ label }} – {% if value == 'reguler' %}lahan yang ditawarkan untuk dimohonkan dan dinilai berdasarkan rencana usaha.{% elif value == 'langsung' %}pengalokasian langsung untuk kegiatan tertentu sesuai ketentuan.{% else %}lahan siap bangun yang dokumen teknisnya tersedia dan pematangan lahannya selesai.{% endif %}
    • {% endfor %}

Biaya: Uang Wajib Tahunan (UWT) sesuai tarif lahan × luas × jangka waktu{% if config.allocation_admin_fee %}, ditambah biaya administrasi {{ config.allocation_admin_fee|rupiah }}{% endif %}. Jangka waktu bawaan {{ config.default_term_years }} tahun.

Hasil: Keputusan Pengalokasian Tanah (KPT) dan Perjanjian Pemanfaatan Tanah (PPT) elektronik ber-QR.

Cari lahan

Izin peralihan hak atas tanah

Pemegang alokasi aktif dapat mengajukan persetujuan peralihan hak kepada pihak lain yang sudah memiliki akun pemohon.

Biaya administrasi: {% if config.transfer_admin_fee or config.transfer_fee_per_m2 %}{{ config.transfer_admin_fee|rupiah }}{% if config.transfer_fee_per_m2 %} + {{ config.transfer_fee_per_m2|rupiah }} per m²{% endif %}{% else %}sesuai ketentuan yang berlaku{% endif %}.

Hasil: Surat Izin Persetujuan Peralihan Hak Atas Tanah elektronik ber-QR; alokasi beralih ke penerima hak.

Ajukan dari menu Akun Saya › Alokasi › Ajukan peralihan hak.

Tahapan proses

  1. Pendaftaran akun
    Data pemohon/badan usaha, aktivasi surel.
  2. Permohonan & dokumen
    Isi rencana usaha, unggah persyaratan, ajukan.
  3. Verifikasi teknis
    Penilaian berbobot oleh tim lintas unit; nilai minimum {{ config.passing_score|floatformat:"-2" }}.
  4. Keputusan
    Disetujui, diminta perbaikan, atau ditolak dengan alasan.
  5. Pembayaran
    Tagihan terbit, jatuh tempo {{ config.invoice_due_days }} hari; unggah bukti bayar.
  6. Penerbitan dokumen
    KPT & PPT (atau izin peralihan) terbit otomatis setelah lunas.
  7. Pelaporan
    Lapor perizinan & pembangunan minimal tiap {{ config.report_interval_months }} bulan.
